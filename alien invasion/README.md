# Практическая работа 1. Игра "Инопланетное вторжение"
## Цель работы
Разработать игру «Инопланетное вторжение», в которой игрок управляет кораблём и должен уничтожить флот инопланетян. Работа позволит вам познакомиться с основами разработки игр на Python с помощью библиотеки pygame и позволит применить эти знания о компьютерной графике, анимации и управлении событиями в дальнейшем.
## Главные герои
Корабль - Меллстрой
Инопланетяне - собачки из одного слота онлайн-казино

Меллстрой стреляет деньгами и убивает казино собак.
