Игра «Инопланетное вторжение»

Установка:
1. Установите Python 3.10 или новее.
2. В терминале выполните:
   python -m pip install pygame

Запуск:
   python alien_invasion.py

Управление:
- Стрелки влево/вправо или A/D — движение корабля.
- Пробел — выстрел.
- R — начать заново после проигрыша.

Структура:
- alien_invasion.py — главный цикл и логика игры.
- settings.py — настройки.
- ship.py — корабль игрока.
- bullet.py — снаряды.
- alien.py — инопланетяне.

Реализовано:
- движение корабля;
- стрельба и удаление снарядов;
- флот инопланетян с горизонтальным движением и спуском;
- столкновения;
- 3 жизни;
- очки и уровни;
- увеличение сложности;
- перезапуск после проигрыша.

Графика сделана средствами Pygame, поэтому дополнительные изображения не нужны.
